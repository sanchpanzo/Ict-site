About the Project

SalesPulse is a web-based platform for sales analysis and visualization of key business indicators, developed as a university project for the Information and Communication Technologies (ICT) course at Narxoz University, School of Digital Technologies.

The platform demonstrates how modern front-end technologies — HTML5, CSS3, and vanilla JavaScript — can be used to build interactive dashboards, AI-powered assistants, and data-driven visualizations without any frameworks or build tools.

The dashboard is powered by index_1.csv: 3,636 real coffee-shop transactions recorded between 1 March 2024 and 23 March 2025. Each row contains a date, time, payment method, anonymised card number, drink category and product name with its USD price.

Technologies Used

The core technical building blocks powering the client-side architecture of SalesPulse.

🌐

HTML5

Semantic document structure ensuring high web accessibility (WCAG), clean heading hierarchies, and standard audio/video integration.

🎨

CSS3

Modern responsive styling using custom CSS variables, CSS Grid, Flexbox, media queries, and smooth hardware-accelerated animations.

⚡

JavaScript ES6+

Framework-free vanilla JavaScript featuring arrow functions, array aggregation methods, dynamic DOM updates, and custom client-side routing.

📈

Chart.js

High-performance canvas-based charting library rendering responsive bar, line, and doughnut visual representations of retail sales metrics.

🔤

Google Fonts

Typography powered by 'Poppins' for clear geometric headings and 'Inter' for highly legible, balanced interface copy across all devices.

🚀

GitHub Pages

Continuous deployment and fast, reliable worldwide hosting directly from the version-controlled Git project repository.
